**Environment facts (verified, not just assumed from spec):**
- Fonts installed on this machine: DejaVu family + Noto CJK. **No Manrope, no Inter, no
  bold DejaVu Sans is missing** — `DejaVuSans-Bold.ttf` at
  `/usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf` exists and is used for any Pillow-rendered
  text (og.png, apple-touch-icon.png) since Manrope/Inter aren't on disk. Browsers still render
  the actual `favicon.svg` with the CSS-declared `font-family: Manrope, Inter, Arial` (Google
  Fonts, loaded at runtime) — the DejaVu substitution only affects locally rasterized PNGs.
- `soffice`/`libreoffice` **is** available (`/usr/bin/soffice`) → docx→pdf conversion works via
  `soffice --headless --convert-to pdf --outdir <dir> <file>`. Used for `can-report.pdf` (from
  `CAN_project_report.docx`), took a normal amount of time, produced valid extractable text
  (verified with `pdftotext`).
- No `cairosvg`, no `rsvg-convert`, no `inkscape` on this machine → cannot rasterize
  `favicon.svg` locally to sanity-check pixel rendering. Verification of the SVG monogram is
  visual/manual only; the apple-touch-icon.png (Pillow-drawn, not SVG-rasterized) is the only
  actual raster proof, and it renders clearly at 180×180.

**favicon.svg (final, confirmed working):** 32×32 viewBox, `<rect rx="6.4">` (20% of 32) fill
`#12395F` (the `--navy` token from 01-design-system.md), white "JH" text,
`font-family="Manrope, Inter, Arial, sans-serif"`, `font-weight="800"`, `font-size="16"`,
`letter-spacing="-0.5"`. `assets/img/apple-touch-icon.png` mirrors this at 180×180 via Pillow
using DejaVu Sans Bold (see above) sized `round(180*0.46)`.

**`_headers` (Cloudflare Pages, exact content used this round):**
```
/docs/*
  X-Robots-Tag: noindex

/assets/img/*
  Cache-Control: public, max-age=31536000, immutable

/assets/pdf/*
  Cache-Control: public, max-age=31536000, immutable

/assets/css/*
  Cache-Control: public, max-age=3600

/assets/js/*
  Cache-Control: public, max-age=3600

/*.html
  Cache-Control: public, max-age=0, must-revalidate
```
This is 06-assets-seo-performance.md §3 literally, split into `/assets/img/*` + `/assets/pdf/*`
(immutable 1y) vs `/assets/css/*` + `/assets/js/*` (max-age=3600) per that section's prose. Note:
this round's task explicitly scoped `_headers` to "exactly per 06 section 3", which is **narrower**
than my base agent instructions (which also want `/temp/*` noindex and a global
`X-Content-Type-Options: nosniff`). Those two extras were deliberately left out this round —
add them if a future task asks for the fuller version.
